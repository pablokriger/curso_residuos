Bienvenidos

Este espacio fue creado como complemento del aula virtual del curso. Aquí encontrarán actividades, ejercicios y recursos especialmente diseñados para trabajar con herramientas que requieren funcionalidades que Moodle no siempre permite desarrollar.

Por eso, esta página no reemplaza al aula virtual: la complementa.

¿Cómo funciona?

Las consignas y materiales de cada actividad se indicarán desde el aula de Moodle. Cuando una actividad requiera utilizar este sitio, encontrarán aquí el acceso correspondiente.

Una extensión del aula virtual

Moodle continúa siendo el espacio principal del curso para acceder a los contenidos, participar de los encuentros y realizar las actividades habituales.

Este sitio se utiliza únicamente cuando necesitamos incorporar herramientas específicas, interfaces interactivas, mapas, visualizaciones, simulaciones u otras funcionalidades que permitan desarrollar actividades que excedan las posibilidades del aula virtual.

Importante:

Cada actividad indicará claramente qué debe realizarse, qué información debe utilizarse y cómo entregar o registrar los resultados en el aula virtual.
